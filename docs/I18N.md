# i18n status: N/A

mrf-honest does not implement internationalization at its current stage.

**Reason:** the project is at phases 0-1 of its implementation plan: a standard-library streaming
reader and a discovery module, operated locally by the single maintainer. There is no user-facing
surface of any kind yet (no HTML, no CLI product, no published site), so there are no
user-facing strings to localize. Operator output and documentation are English-only by design.

**Scope note:** the source data is US price-transparency filings; amounts are USD and field
names are fixed by CMS schemas. That is a property of the data, not a localization decision.

**Revisit if:** phase 5 of `docs/IMPLEMENTATION-PLAN.md` ships the public static site and API.
A public price-comparison site is a civic-adjacent surface, and the language question must be
re-decided (not silently carried over) before it launches.

Last verified: 2026-08-07. Recheck: at phase 5 planning, or on any earlier scope change.
